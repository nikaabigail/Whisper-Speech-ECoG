# Зафиксированный fit-only результат

Здесь сохранён компактный аудиторский снимок завершённого прогона
`contextual_covariance_alternating_v2_sub01`. Это линейный alternating-контроль на
development-пациенте `sub-01`, основанный на последнем contextual L4-протоколе.

## Что получилось на validation

| Вариант | Средний Pearson `r` |
|---|---:|
| Фиксированный PCA50, цикл 0 | 0,494094 |
| Выбранный alternating | 0,496015 |
| Парная разница | +0,001921 |

Выбранные циклы по пяти фолдам: `[1, 0, 0, 0, 1]`. В трёх фолдах validation
не подтвердил улучшение, поэтому gate корректно сохранил исходный PCA50-контроль.

Это **не глубокий end-to-end прогон**. Здесь поочерёдно решались точные линейные
подзадачи OLS-декодера и ортонормированного проектора `128→50`. Whisper и
контекстные ECoG-признаки не дообучались. Именно поэтому вычисление заняло около
минуты на CPU.

## Граница доступа к test

На момент фиксации:

- во всех пяти receipts стоит `test_evaluated=false`;
- файла разрешения на test нет;
- итогового test-summary нет;
- сохранены только validation-метрики и хеши локальных артефактов.

Поэтому числа выше нельзя выдавать за итоговую test-точность или за
популяционный результат.

## Содержимое фиксации

[`development_fit_only_20260730.json`](development_fit_only_20260730.json)
содержит протокол, результаты каждого validation-фолда, выбранные циклы,
fingerprints и SHA-256 исходных локальных артефактов. Большие `NPZ`, покадровые
предсказания, кэши и логи в Git не копируются.

Полный локальный run остаётся в:

```text
C:\WhisperECoG_Work\SWPD\runs\contextual_covariance_alternating_v2_sub01
```

По сохранённым хешам проверены все пять `selected_artifact.npz`, все пять
`validation_predictions.npz` и все пять `selection_frozen.json`. Максимальная
ошибка воспроизведения cycle-0 PCA50 равна `9,49×10⁻¹⁵`; дисперсия всех 50
проекций остаётся единичной, поэтому нулевого collapse нет.

Отдельный настоящий end-to-end эксперимент должен иметь собственный run и
собственную фиксацию, чтобы его нельзя было перепутать с этим линейным контролем.
