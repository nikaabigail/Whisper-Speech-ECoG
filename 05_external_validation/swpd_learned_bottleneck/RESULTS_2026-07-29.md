## Decisions

1. The one-shot supervised RRR50 projector is rejected: it did not improve the
   common MEL probe for any Whisper target.
2. CLIP50 is rejected in its current form. The Stiefel constraint prevented the
   literal all-zero target projector, but test cosine margin was approximately
   zero and neural effective rank was only 11–17 of 50. Its common MEL score was
   below PCA50 for every target.
3. More CLIP epochs are not justified solely because validation InfoNCE was still
   decreasing: train distinguishability did not transfer to held-out temporal
   blocks, and the contrastive validation objective is not the publication
   regression metric.
4. The next development-only test is constrained alternating optimization:
   refit the decoder with the projector fixed, then update the orthonormal target
   projector with the decoder fixed. This test is now complete. Validation selected
   the initial PCA projector (iteration 0) for 23/25 fold/target tasks. It selected
   iteration 1 only for L3 and L5 in fold 4; both selections reduced held-out test
   MEL correlation. The alternating method is therefore rejected.
5. PCA50 remains the selected development method. L5 has the numerically highest
   full-MEL mean (`0.281028`), while L4 has the numerically highest lower-20-bin
   mean (`0.296819`). These differences are tiny and are not patient-level
   inferential evidence.
