# 03 · Ансамбль Whisper L3+L4+L5

[← Whisper sync](../02_whisper_sync/README.md) · [На главную](../README.md) ·
[Асинхронный этап →](../04_whisper_async/README.md)

Ансамбль объединяет три синхронные модели, обученные на target-представлениях
Whisper L3, L4 и L5. Для каждого примера усредняются softmax-вероятности, после
чего выбирается класс с максимальной итоговой вероятностью.

```text
              ┌─ L3 logits ─ softmax ─┐
нейронное окно├─ L4 logits ─ softmax ─┼─ среднее ─ argmax
              └─ L5 logits ─ softmax ─┘
```

Это ансамбль **слоёв одного сида**, а не голосование разных случайных
инициализаций. Наиболее честное сравнение — с лучшим одиночным слоем на тех же
445 тестовых примерах.

## Актуальные файлы

| Файл | Назначение |
|---|---|
| `ensemble_layers.py` | оценка заранее фиксированного L3+L4+L5 одного сида |
| `run_ensemble.ps1` | рекомендуемая PowerShell-обёртка |

Скрипты ожидают соседнюю папку `../02_whisper_sync`; другое расположение можно
передать через переменную окружения `OSSADTCHI_SYNC_ROOT`.

## Запуск

После подготовки трёх пар encoder+word-head одного seed:

```powershell
.\run_ensemble.ps1 -Patient ivanova -Layers 3,4,5 -Seed 4
```

Это воспроизводит балансированную headline-поверхность, используемую в главной
таблице. `-FullTest` переключает метрику на другую, несопоставимую поверхность;
не смешивайте эти два отчёта.

## Результат

Пациент `ivanova`, `seed=4`, `n=445`:

| Система | Accuracy | Δ к лучшему одиночному |
|---|---:|---:|
| L3 | 0,7708 | — |
| L4 | 0,7618 | — |
| L5 | 0,7393 | — |
| **L3+L4+L5** | **0,8135** | **+0,0427** |

Относительно L4 прирост равен `+0,0517`. Небольшое расхождение с округлённым
`+0,043` в консольном отчёте связано только с числом знаков после запятой.

## На что обратить внимание

- все три модели должны относиться к одному пациенту, split и seed;
- порядок тестовых примеров обязан совпадать;
- ансамбль строится из вероятностей, а не из уже выбранных меток;
- состав `L3+L4+L5` фиксируется до просмотра теста;
- отсутствие части весов — ошибка, а не повод незаметно заменить состав.

Исторический exploratory-отчёт, где для каждого сида выбирался лучший поднабор
слоёв прямо по test, удалён из минимального релиза: его нельзя выдавать за
заранее фиксированный multiseed L3+L4+L5. Здесь основным остаётся прозрачно
зафиксированный результат `seed=4`.
